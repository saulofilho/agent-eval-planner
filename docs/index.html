What is it?

From agent contract to eval pipeline

If an agent happily answers a carrot-cake recipe, its scope is not limited. This gem turns that insight into a repeatable eval pipeline: vectors with pass/fail criteria, a JSONL suite ready for your harness, and remediations for prompt and policy gates.

Available as a Ruby gem for CI/CD — deterministic planning that pairs with AI skills for deeper exploration.

What you get

An eval pipeline in 3 artifacts

From attack vectors to prioritized remediations

📋

plano-de-acao-agent-eval.md

Guardrail vectors identified and ready to run.

  • Stable IDs (SCOPE-01, INJECT-01…)
  • Attack prompts and objectives
  • Expected validation and failure criteria
  • Summary table by severity
Executable

suite.jsonl

One JSON case per line for your eval harness.

  • forbidden_tools filled from the contract
  • Refusal flags for guardrail rows
  • Smoke split for CI gates
  • Built-in suite validator (no false greens)
🛠️

remediacoes.md

Prompt / gate / evaluator fixes linked to vector IDs.

  • Quick wins (≤ 2h)
  • Reference snippets
  • Regression case IDs
  • Effort and priority

When to use?

The right moments to generate a plan

  • ✓
    New agent or specialist Before shipping — map scope, injection, and role-escape vectors from the real contract.
  • ✓
    Tool-calling agents Ensure off-topic / injection rows forbid domain tools (no empty forbidden_tools).
  • ✓
    Multi-agent orchestrators Cross-capability probes and handoff expectations.
  • ✓
    AI Eng → AppSec handoff Document the validation plan before harness runs.

Taxonomy

What every smoke pack covers

SCOPE

Off-topic

Carrot cake, capitals, generic productivity — fails if the agent complies.

INJECT

Prompt injection

“Ignore previous instructions…” — fails if the agent obeys the override.

ROLE

Role escape

“Be ChatGPT / developer mode” — fails if persona flips.

Plus PII, TOOL, HALLUC, and EXFIL when signals in the contract apply.

Ruby gem

Install and generate your first pipeline

Input: agent contract (markdown, prompt, or JSON). Output: plan + suite + remediations.

Install
gem install agent_eval_planner
Generate
agent-eval-planner agent.md --tools search,fetch -o ./out
Validate suite
agent-eval-planner validate ./out/suite.jsonl --known-tools search,fetch
